- 正式登录和 token 生命周期后续统一处理。
- MVP 阶段封面 URL 标准固定为 `/uploads/coffee-covers/{filename}`。
- 不再混用 `/files` 作为图片静态访问前缀。
- 本地 uploads 存储策略 MVP 阶段可接受。
