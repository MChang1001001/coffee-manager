# v0.3 本地 smoke 残留清理脚本

## 用途

`scripts/clean-smoke-data.mjs` 用于清理 `node scripts/local-smoke.mjs` 在本地 MySQL 和本地 uploads 目录中留下的可安全识别残留。

它只面向本地个人开发环境，不是生产清理工具，不改变数据库结构，不引入 migration 工具，也不影响本地 exe 启动器。

## 使用方式

默认是 dry-run，只预览，不删除：

```powershell
node scripts\clean-smoke-data.mjs
```

显式 dry-run：

```powershell
node scripts\clean-smoke-data.mjs --dry-run
```

执行真实清理：

```powershell
node scripts\clean-smoke-data.mjs --execute
```

安全提醒：执行 `--execute` 前请先运行一次 dry-run，确认扫描数量和文件路径符合预期。

如果同时传入 `--dry-run` 和 `--execute`，脚本会报错退出，不做清理。

## 清理范围

数据库清理范围：

- `coffee_beans` 中字段包含 `[SMOKE_TEST]` 的 coffee 记录。
- 与这些 smoke coffee 通过 `coffee_bean_id` 关联的 `coffee_reviews`。
- 与这些 smoke coffee 通过 `coffee_bean_id` 关联的 `brew_records`。
- 上述记录会按明确 smoke 标记做物理删除，包含 `deleted=0` 和 `deleted=1`，但只限 `[SMOKE_TEST]` 相关数据。

上传文件清理范围：

- 只清理 smoke coffee 记录中 `cover_image_url` 指向的 `/uploads/coffee-covers/{filename}` 文件。
- 如果未显式设置 `FILE_UPLOAD_PATH`，脚本会兼容扫描项目根目录 `uploads` 和 `backend/uploads`。
- 如果显式设置了 `FILE_UPLOAD_PATH`，脚本会优先使用该配置。

## 不会清理哪些内容

- 不清理正常 coffee bean。
- 不清理所有逻辑删除记录。
- 不清理没有 `[SMOKE_TEST]` 关联的数据。
- 不清理没有关联到 smoke coffee 的 review 或 brew record。
- 不清理无法从 smoke coffee 数据库记录明确识别归属的上传文件。
- 不修改后端接口、前端页面、数据库结构、本地启动脚本或 exe 启动器文档。

## 输出说明

脚本会输出：

- 当前模式：`dry-run` 或 `execute`。
- 扫描到的 smoke coffee 数量。
- 扫描到的关联 review 数量。
- 扫描到的关联 brew record 数量。
- 扫描到的可安全清理上传文件数量。
- 实际清理数量。
- 跳过数量。
- 错误数量。
- 最终结果：`CLEAN_SMOKE_RESULT: PASS` 或 `CLEAN_SMOKE_RESULT: FAIL`。

## 配置读取

数据库连接读取方式与后端保持一致：

- `backend/src/main/resources/application.yml`
- `DB_URL`
- `DB_USERNAME`
- `DB_PASSWORD`

上传目录读取方式：

- `backend/src/main/resources/application.yml` 中的 `app.file.upload-path`
- `FILE_UPLOAD_PATH`

脚本通过本机 MySQL 客户端执行 SQL。如果 `mysql` 不在 PATH，会尝试常见 Windows 安装路径。也可以显式设置：

```powershell
$env:MYSQL_CLIENT_PATH='C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe'
```

## 常见问题

### MySQL 未启动

脚本会连接失败并输出 `CLEAN_SMOKE_RESULT: FAIL`。先启动本机 MySQL，并确认 `DB_URL` / `DB_USERNAME` / `DB_PASSWORD` 与后端配置一致。

### 上传目录不存在

不致命。脚本会报告缺失目录，并继续清理数据库中可识别的 smoke 数据。

### 没有 smoke 数据

脚本会输出 0 条 smoke coffee、0 条关联 review、0 条关联 brew record，最终仍应为 `CLEAN_SMOKE_RESULT: PASS`。

### 文件无法安全识别

当前上传落盘文件名是 UUID，不保留 smoke 原始文件名前缀。脚本只删除数据库中 smoke coffee 的 `cover_image_url` 明确指向的文件；其他 uploads 文件只报告为跳过。

### `mysql` 命令不可用

确认 MySQL 客户端已安装并在 PATH 中，或设置 `MYSQL_CLIENT_PATH` 指向 `mysql.exe`。
