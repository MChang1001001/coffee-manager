# Coffee Manager v0.2 本地版 Release Notes

## 版本定位

v0.2 本地版是 v2 阶段的总收口版本，目标是保持本地开发、本地 MySQL、本地 Vite、本地 Spring Boot 和本地 uploads 目录的可复现启动。当前暂无上线部署计划，数据库结构继续通过手动 SQL 管理，不引入 migration 工具。

## 已完成能力

1. 日系手账风 Coffee 首页。
2. Coffee CRUD 主链路。
3. 封面上传与展示。
4. 评价 CRUD。
5. 冲煮记录 CRUD。
6. 养豆期 / 赏味期字段。
7. 饮用状态展示。
8. Coffee 档案详情页。
9. 详情页最近评价摘要。
10. 详情页最近冲煮摘要。
11. 本地 exe 启动器一期。
12. 本地烟测脚本。

## 启动方式

开发启动：

```powershell
cd backend
mvn spring-boot:run
```

```powershell
cd frontend
npm install
npm run dev
```

默认访问：

```text
http://localhost:5173/coffee
http://localhost:5173/coffee-beans/{id}
```

本地烟测：

```powershell
node scripts\local-smoke.mjs
```

本地启动器：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\local-start.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\local-status.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\local-stop.ps1
```

也可以双击：

```text
launcher/喝咖啡.exe
```

日志查看：

```powershell
Get-Content .\logs\backend.log -Tail 120
Get-Content .\logs\frontend.log -Tail 120
Get-Content .\logs\backend.log -Wait
Get-Content .\logs\frontend.log -Wait
```

## 常见问题

- MySQL 未启动或账号密码不匹配：先启动 MySQL，再检查 `DB_URL`、`DB_USERNAME`、`DB_PASSWORD`。
- 端口被占用：运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\local-status.ps1` 查看 `8080` / `5173` 占用情况。
- Maven / Node / npm 不可用：确认 `mvn`、`node`、`npm` 已加入 PATH。
- 前端依赖缺失：在 `frontend` 目录运行 `npm install`。
- 上传目录不可写：显式设置 `FILE_UPLOAD_PATH`，或确认项目根目录下 `uploads` 可写。
- exe 无法启动完整应用：exe 只是启动器，不包含 MySQL、Java、Maven、Node、npm，也不会自动安装前端依赖。

## 当前延后事项

1. migration 工具暂不引入。
2. 正式登录和 token 生命周期延后。
3. `review_count` / `brew_count` / `overall_rating` 聚合回写延后。
4. 赏味期排序 / 提醒 / 推荐算法延后。
5. 风味标签体系延后。
6. 统计图表延后。
7. 移动端专项适配延后。
8. Docker / 上线部署延后。
9. 图片旧文件清理延后。
10. OCR 延后。

## 当前已接受行为 / 风险

1. 烟测会产生 `[SMOKE_TEST]` 逻辑删除记录。
2. 烟测会产生本地上传文件。
3. 历史旧封面文件缺失时使用兜底占位。
4. 详情页“最近评价 / 最近冲煮”依赖现有后端排序。
5. 当前仍以本地个人使用为目标。

## 定版结论

在前端构建和本地烟测均通过的前提下，建议将当前版本定义为 v0.2 本地版阶段性完成。
